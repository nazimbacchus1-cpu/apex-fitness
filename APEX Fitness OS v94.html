📖 How to Use APEX Fitness OS
Tap any section to expand
🚀First-Time Setup
▼
1. Profile — Settings → enter name, age, sex, height, weight, activity level → pick a goal card → tap Save Settings.
2. Install as app — iPhone: Safari → Share ⬆ → Add to Home Screen. Android: Chrome → ⋮ menu → Add to Home Screen.
3. Set up Periodization — AI Coach tab → Periodization Engine → answer 3 questions (goal / experience / weeks) → Start My Programme.
4. Log your first sleep — Dashboard → tap the Sleep bar → enter last night's hours → Save Sleep.
5. Log water — Dashboard → tap any 💧 glass to fill it as you drink. Target resets automatically each day.
6. Log a meal — Nutrition → + Log Meal → type food → Find Macros → Add to Today. Saved automatically to your personal food database.
7. Apple Health Sync (Apple Watch users) — Settings → 🍎 Apple Health Sync → follow the Shortcuts setup. Once configured, run the Shortcut each morning to auto-import steps, sleep, resting HR and HRV into the app in one tap.
8. API Key (optional) — Settings → 🔑 Anthropic API Key → paste your key for AI-powered meal lookup and full AI Coach answers. Get a key free at console.anthropic.com.
📅Daily Routine
▼
Morning — Dashboard → tap Sleep bar → log last night's hours. Check your 4 KPI tiles (weight, calories, water, streak).
Log meals — Nutrition → + Log Meal → type food name → Find Macros → Add to Today. Type 3+ chars to see saved foods auto-suggest.
Multi-food entry — Type combined meals like "1/2 avocado and banana" or "chicken rice and broccoli" — macros are summed automatically.
Manual macros — If no match found, a manual entry form appears. Fill in kcal / protein / carbs / fat → Use These Macros → Add to Today. Saved for future use.
My Foods — Nutrition → + Log Meal → 📚 My Foods → view all saved foods sorted by most-used. Tap any to load instantly.
Log water — Dashboard → tap 💧 glasses throughout the day. Progress bar and KPI tile update live.
Log workout — Workout → expand any template → Log Session (quick) or Start Active Workout (full tracking with timer + sets).
Weekly check-in — AI Coach → Adaptive Plan Engine → enter current weight → Analyse & Adapt. Repeat every 7 days.
💪Active Workout Mode
▼
Start — Workout → expand any template → Start Active Workout. Full-screen mode launches with elapsed timer.
Log a set — Enter weight and reps → tap Log Set. Rest timer starts automatically between sets.
Personal bests — 🏆 badge appears automatically when you beat a previous weight or reps record.
Finish — Tap Finish Workout → see session summary (time, sets, calories, PRs). Streak and KPIs update immediately.
Quick log — For a faster option, tap Log Session directly on the template — logs the burn without entering sets.
Training streak — Every logged session (quick or active) marks that calendar day. Streak counts consecutive days with at least one session.
🥗Nutrition & Meals
▼
Food lookup — Type specific descriptions. "Grilled chicken 200g" matches better than just "chicken". Specific dishes like "chili chicken" won't false-match to generic chicken.
Personal DB — Every confirmed meal is saved. Next time you type 3+ chars, matching saved foods appear in a dropdown — tap to load instantly.
API key — Add your Anthropic API key in the Log Meal modal for AI-powered macro lookup of any food, including dishes and restaurant items.
Meal plan — Nutrition → Week tab → see your 7-day plan. Tap ⇄ Swap on any slot to pick a different meal. ↺ Reset clears all swaps.
Grocery list — Nutrition → Grocery tab → aggregated shopping list from your current week plan with quantities and categories.
Macro rings — Dashboard shows protein / carb / fat rings filling live as you log meals throughout the day.
Heatmap — Analytics shows weekly macro adherence — green = on target, red = over, grey = no data.
🔄Periodization Engine
▼
Setup — AI Coach → Periodization Engine → answer goal / experience / weeks → Start My Programme.
Apply macros — Current phase shows target calories and macros. Tap ✓ Apply Macros to sync them to your active targets.
Skip phase — Tap Skip Phase → to advance early if you feel ready to move on.
Timeline — Colour-coded bar shows all phases (Foundation → Peak → Deload etc.) with current phase highlighted.
TDEE modifier — Each phase shows its calorie adjustment (e.g. TDEE −15%, TDEE +10%) so you know exactly why targets change.
Reset — To start a new programme, re-open the Periodization Engine and complete the 3-question setup again.
🧬Recovery Score
▼
What it measures — A 0–100 composite across 8 live factors. Updates every time you log sleep, water, meals, or a workout.
Sleep Quantity (20%) — Log via Dashboard → Sleep bar. Tap to enter hours → Save Sleep.
Acute Fatigue (10%) — Automatically calculated from sessions logged in the last 48 hours.
Calorie Adequacy (15%) — Uses your actual logged calories vs training-day needs. Log meals for accuracy.
Protein Adequacy (15%) — Uses your actual logged protein vs daily target. Log meals for accuracy.
Rest-to-Train Ratio (15%) — Counts distinct training days this week from your workout calendar. Ideal: 4–5 sessions with 2–3 rest days.
HRV / Resting HR (10%) — Requires wearable integration. Shows neutral 70/100 without a device.
Training Load Balance (10%) — Scores the mix of high vs low intensity sessions this week.
Hydration (5%) — Uses tapped glasses from the Dashboard water widget.
🤖AI Coach Chat
▼
Without API key — Answers questions about your macros, calories, protein, carbs, fat, streak, recovery score, sleep, water, TDEE/BMR, and periodization phase using your real live data.
With API key — Full Claude AI answers any fitness question with your complete profile as context. Add key in the Log Meal modal (tap Find Macros).
What to ask — "how are my macros", "what's my recovery score", "how many sessions this week", "what phase am I in", "how much protein do I need", "am I on track to hit my goal".
Adaptive Plan — AI Coach → Adaptive Plan Engine → enter current weight → get a personalised macro and calorie adjustment based on recent progress.
🍎Apple Health Sync Setup
▼
What it does — Imports steps, sleep hours, resting heart rate, and HRV from Apple Watch via iPhone Shortcuts. Data feeds directly into the Recovery Score, Steps bar, Sleep bar, and all 8 recovery factors.

One-time setup:
Step 1 — On your iPhone open the Shortcuts app (pre-installed on iOS 13+).
Step 2 — Tap + (top right) to create a new shortcut. Name it "APEX Health Sync".
Step 3 — Tap Add Action → search "Health" → select Find Health Samples. Add four of these actions:
📊 Find Health Samples → Step Count → Last Day → Sort Newest First → Limit 1
😴 Find Health Samples → Sleep Analysis → Last Day → Sort Newest First → Limit 1
❤️ Find Health Samples → Resting Heart Rate → Last Day → Sort Newest First → Limit 1
📡 Find Health Samples → Heart Rate Variability → Last Day → Sort Newest First → Limit 1
Step 4 — Add one more action: Open URL. Tap URL field → build the URL using the magic variable tokens Shortcuts provides. The URL structure is:
[your-app-url]?apex_health=1
&steps=[Step Count value]
&sleep=[Sleep Analysis value]
&hr=[Resting Heart Rate value]
&hrv=[Heart Rate Variability value]
Step 5 — Go to Settings → 🍎 Apple Health Sync → tap 📋 Copy URL Template to get your app's exact URL pre-filled. Paste it into the Open URL action in Shortcuts.
Step 6 — Tap the play ▶ button in Shortcuts to test it. APEX should open, show a green "✓ Apple Health synced" toast, and update your bars immediately.
Step 7 (optional) — Add the shortcut to your home screen or lock screen widget for one-tap morning sync.

Daily use — Run APEX Health Sync each morning. Takes 2 seconds. Imports last night's sleep, overnight HRV, resting HR, and yesterday's step total. All Recovery Score factors update automatically.

Troubleshooting — If no data imports, check iPhone Settings → Privacy → Health → Shortcuts → make sure all four data types are enabled for Read access. Apple Watch must have synced to iPhone before you run the Shortcut.
